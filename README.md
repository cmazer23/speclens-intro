## Publish yourself on GitHub Pages

1. Sign in to your GitHub account with a verified email.
2. Create a public repository, for example speclens-intro.
3. Choose Add file > Upload files. Upload the CONTENTS of this folder, not the outer folder or ZIP. index.html must be at the repository root. Preserve assets/speclens-comparison.png.
4. Commit the upload to main.
5. Open repository Settings > Pages. Choose Deploy from a branch, branch main, folder /(root), then Save. Leave Custom domain empty.
6. Wait for the Pages deployment to succeed under Actions, then open Settings > Pages > Visit site.
7. Open that live website in a private window and on a phone. Check View demo preview, the image, and Read the saved sample report.

Use the resulting github.io website URL for sharing, not the GitHub repository URL or a file:/// or localhost URL. Pages displays the introduction; it does not run the Python backend.

Only publish the files listed above. Do not upload the full SpecLens project, .env, API keys, source documents, or Python scripts.
